# Vistynq — документация

**Vistynq** — веб-приложение для работы с заметками как с графом знаний: каждая заметка живёт на бесконечном канвасе в виде ноды, заметки связываются друг с другом прямыми и косвенными ссылками, навигация строится на тегах, важности и наглядных связях.

## Основные концепты

| Понятие | Описание |
|---|---|
| **Канвас** | Бесконечное графическое поле. У пользователя может быть неограниченно много канвасов. |
| **Заметка (нода)** | Единица контента. Всегда принадлежит ровно одному канвасу. На канвасе отображается прямоугольной нодой, на которой виден только заголовок. |
| **Манифест заметки** | Структурированные метаданные: заголовок, теги, важность, актуальность, видимость. Хранится в БД, редактируется через UI-форму (не как код). |
| **Тело заметки** | Markdown-текст с wiki-ссылками вида `[[...]]`. |
| **Прямая ссылка** | Связь, заданная вручную на канвасе. Сплошная линия со стрелкой. |
| **Косвенная ссылка** | Связь из `[[wikilink]]` внутри markdown-текста. Пунктирная линия со стрелкой. |
| **Атрибуты** | Важность 1–5 (по умолчанию 3), актуальность (актуальна / «неактуально» → в архив). |
| **Теги** | Локальны для канваса, имеют цвет, переименовываются и удаляются централизованно. |
| **Владелец / автор** | Создатель канваса (владелец) или заметки (автор) — один и тот же человек для своего ресурса, с полными правами. Только он выдаёт доступ и меняет видимость. |
| **Доступ** | Канвас: `private` (владелец + те, кому выдан доступ) или `public` (любой по ссылке, только чтение); по умолчанию `private`. Заметка: `public` (видна всем, кто видит канвас) или `private` (автор, владелец канваса и выданные на неё). Роли выдачи: `viewer` / `editor`; доступ существующему пользователю действует сразу. |

## Стек

- **Backend:** ванильный PHP ≥ 8.2 (без фреймворка), PostgreSQL, REST JSON API, JWT (access в памяти клиента + refresh в httpOnly-cookie), S3-совместимое хранилище (MinIO), Composer-пакеты: `nikic/fast-route`, `firebase/php-jwt`, `aws/aws-sdk-php`, `phpmailer/phpmailer`.
- **Frontend:** Vue 3 + TypeScript + Vite, Pinia, Vue Router, vue-i18n (RU/EN), свой CSS без UI-библиотек (headless-примитивы Reka UI), канвас — Vue Flow, редактор — Tiptap.
- **Инфраструктура:** docker compose (nginx + php-fpm, postgres, test-postgres, minio, mailpit).
- **Именование:** JSON и код — `camelCase`, БД — `snake_case`.

Realtime-коллаборация, история версий заметок, полнотекстовый поиск по markdown-телу (Postgres FTS), мобильная версия, векторное рисование и размещение медиа прямо на канвасе, тёмная тема.

## Быстрый старт (dev)

Основной путь — инфраструктура в docker, приложение на хосте:

```bash
cp .env.example .env                             # сменить пароли и JWT_SECRET
docker compose up -d postgres minio minio-init mailpit
cp apps/backend/.env.example apps/backend/.env   # для работы на хосте: DB_HOST=127.0.0.1
pnpm install
pnpm db:migrate                                  # миграции (bin/migrate)
pnpm dev                                         # turbo: vite (5173) + bin/serve (8000)
curl http://localhost:8000/api/v1/healthz       # {"status":"ok"}
```

Альтернатива — всё в docker (nginx+php-fpm вместо `pnpm dev`, порты 8000/5173 те же, поэтому два способа одновременно не запускаются):

```bash
docker compose up -d                             # + nginx+php-fpm (API), frontend (vite)
docker compose exec backend php bin/migrate
```

Ссылки: фронт `http://localhost:5173` · API `http://localhost:8000/api/v1` · Mailpit `http://localhost:8025` · MinIO console `http://localhost:9001`
