# Гайд пользователя

Vistynq — заметки как граф: каждая заметка — нода на бесконечном канвасе, а связи между заметками видно прямо на схеме.

## 1. Аккаунт

1. **Регистрация** — `https://…/register`: email, пароль (≥8 символов), имя. На почту придёт письмо со ссылкой подтверждения — без подтверждения аккаунт не активен.
2. **Вход** — email + пароль. Сессия живёт долго: «запомнить» реализовано refresh-кукой, доступный токен не покидает вкладку браузера.
3. **Забыли пароль** — «Забыли пароль?» на странице входа → письмо → новый пароль. Все активные сессии при этом сбрасываются.
4. **Профиль** (`/profile`) — имя, email (смена требует повторного подтверждения), аватар. Сменить язык интерфейса: RU/EN.
5. **Выход** — отзывает все токены этого браузера.

## 2. Канвасы

- **Создать**: «+ Создать канвас» на дашборде.
- **Открыть**: клик по карточке. Один канвас = одно пространство заметок.
- **Удалить канвас** — только владелец; удаляет все заметки канваса безвозвратно (с подтверждением).
- **Навигация**: перетаскивание — панорама; Ctrl+колесо — зум к курсору; колесо/Space+drag — тоже панорама.

## 3. Заметки

Создать:
- **ПКМ по пустой области → «Создать заметку»**;
- **ПКМ по ноде → «Создать от этой заметки»** — появится дочерняя нода, а родитель получит к ней стрелку (прямую ссылку);
- **перетащить .md/.txt файл на канвас** — из него создастся заметка.

Редактировать (доступно автору заметки и редакторам канваса):
- **открыть** ноду (двойной клик / ПКМ → «Открыть») — панель с манифестом и markdown-редактором.
- Манифест: **заголовок**, **важность 1–5** (по умолчанию 3 — видно по цвету ноды), **теги** канваса, **актуальность**.
- Текст заметки — обычный markdown.

Архив:
- **«Поместить в архив “неактуально”»** (ПКМ по ноде) — заметка пропадает с канваса, но остаётся доступной по ссылкам, которые на неё ведут; возвращается из панели «Архив».
- **«Удалить»** — тоже в архив (секция «Удалённые»), откуда заметку можно **восстановить**.
- **«Стереть навсегда»** — необратимо; на связанных заметках вместо ссылки появится пометка **«ссылка удалена»** (её видите только вы и те, у кого был доступ).

## 4. Ссылки и теги

- **Прямые** (сплошная линия со стрелкой): ПКМ по ноде → «Ссылка на другую заметку…» → клик по цели. Развернуть/удалить — из меню связи или клавишей Del.
- **Косвенные** (пунктир): в тексте заметки напишите `[[` — откроется автодополнение по заметкам канваса. Ссылка появится на схеме автоматически после сохранения.
- **Теги** пер-канвасные: создаются в редакторе заметки или через меню «Теги». Наведите курсор на тег в меню — все ноды с этим тегом подсветятся. Там же тег можно переименовать, перекрасить, удалить (со всех заметок).
- **Важность**: меню «Важность» — фильтр по уровням 1–5 и тумблер «Показывать неактуальные».

## 5. Файлы в заметках

Перетащите в панель редактирования заметки:
- **картинку** (png/jpg/gif/webp ≤5 МБ) — вставится в текст;
- **аудио** (mp3/ogg/wav ≤25 МБ) — станет файлом-приложением с плеером;
- **текстовый файл** (.txt/.md ≤1 МБ) — содержимое вставится в курсору.

## 6. Доступ и публикация

У каждого канваса и каждой заметки три уровня доступа (диалог «Доступ», по умолчанию «Только я»):

| Уровень | Кто видит | Как дать |
|---|---|---|
| Только я (private) | только вы | — |
| Конкретные пользователи | приглашённые по email | инвайт по email + роль **viewer** (только смотреть) или **editor** (двигать, создавать и редактировать заметки на канвасе) |
| Публичная ссылка | все, включая анонимов | «Публичная ссылка» → скопировать URL; выключается одной кнопкой |

- Редактировать заметку всегда может её автор; редакторы канваса — любые заметки канваса.
- Приглашённый по ссылке канваса видит **только доступные** ему заметки: приватные заметки и ссылки на недоступное не отображаются никак.
- Принять инвайт без регистрации можно заранее: письмо со ссылкой; при регистрации по тому же email инвайты подхватятся автоматически (колокольчик на дашборде).

## 7. Мелочи, которые приятно знать

- Поиск по канвасу (лупа вверху) ищет по заголовкам и тегам, центрирует камеру на найденной ноде.
- Позиции и размеры нод сохраняются автоматически после перетаскивания.
- Если письмо не пришло — на странице входа есть «Отправить письмо ещё раз».
