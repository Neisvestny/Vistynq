# UI/UX спецификация

Язык интерфейса: RU по умолчанию, переключатель EN (vue-i18n). Тёмная/светлая тема — не в v1, только светлая. Все стили — свой CSS, дизайн-токены в `src/styles/tokens.css`.

## Карта экранов и маршруты

| Маршрут | Экран | Доступ |
|---|---|---|
| `/login`, `/register`, `/verify-email`, `/forgot-password`, `/reset-password` | auth | гости |
| `/` | Dashboard (список канвасов) | auth |
| `/canvas/:id` | CanvasView (редактор) | ≥viewer (edit по правам) |
| `/shared/canvas/:slug` | SharedCanvas | анонимы |
| `/shared/note/:slug` | SharedNote | анонимы |
| `/profile` | Настройки профиля | auth |
| `*` | 404 | |

## 1. Dashboard

- Сетка карточек канвасов: название, дата изменения, кол-во заметок, бейдж роли (владелец/editor/viewer), бейдж «публичный» если public_link.
- Кнопка «+ Создать канвас» → модалка с названием → редирект на `/canvas/:id` (пустой канвас с подсказкой-заглушкой «ПКМ — создать заметку»).
- Секция «Приглашения» (колокольчик): входящие инвайты с кнопками Принять/Отклонить.
- Поиск/сортировка канвасов — не в v1.

## 2. CanvasView

Верхняя панель: название канваса (инлайн-edit для owner), поиск по заметкам (лупа, выпадающий список результатов: заголовок + совпавший тег → клик центрирует ноду), кнопки: Теги · Важность · Архив · Доступ · Профиль.

### Ноды

- Прямоугольник ~220px, виден **только заголовок** (1–2 строки, ellipsis).
- Обводка/акцент цвета зависит от важности: 1 — серый slate, 2 — синий, 3 — нейтральный (по умолчанию), 4 — оранжевый, 5 — красный. Легенда в меню важности.
- Состояния: обычная, hover (подсветка), selected (акцент-рамка + handles), drag (тень), «неактуальная» — не рендерится без фильтра; при включённом фильтре — полупрозрачная с бейджем «архив».
- Drag, resize (handles справа/снизу), зум бесконечный (minimap не в v1), панорамирование колесом/SPACE+drag, Ctrl+колесо — зум к курсору.

### Рёбра (линки)

- **Прямые**: сплошная линия, стрелка на конце (направленные родитель → дочерняя).
- **Косвенные** (из `[[...]]` в тексте): пунктирная линия со стрелкой, тоньше, цвет приглушённый.
- **Битые** (tombstone «ссылка удалена»): линия отсутствует/пунктир серого цвета с подписью «ссылка удалена», показывается только тем, кто имел доступ; остальные не видят ничего.
- Выделение ноды подсвечивает все её рёбра; при hover ноды — её связи жирнее.

### Контекстное меню (ПКМ)

**По пустой области канваса:**
1. Создать заметку (в точке клика)
2. Импортировать файл… (текст → новая заметка; аналог drop)
3. Вставить/зум-в центр

**По ноде заметки:**
1. Открыть (редактировать)
2. Создать от этой заметки → спавнит дочернюю ноду рядом + сплошная стрелка родитель → новая
3. Ссылка на другую заметку… → режим связывания (клик по целевой ноде), создание прямой ссылки
4. Теги (подменю: чекбоксы тегов канваса + «новый тег…»)
5. Важность (подменю 1–5)
6. Сделать публичной / приватной (цикл по трём уровням — открывает диалог «Доступ»)
7. Поместить в архив «неактуально»
8. Удалить (soft → в архив удалённых)

Меню — только для ≥editor; viewer видит «Открыть».

### Меню тегов

Панель со списком тегов канваса (чип с цветом). **Hover по тегу** подсвечивает все ноды с этим тегом (остальные — dimmed). Клик по тегу в режиме editor — переименовать/сменить цвет/удалить (подтверждение: «Тег будет удалён из N заметок»).

### Меню важности

Чекбоксы 1–5 + «Показывать неактуальные» + легенда цветов. Фильтр скрывает/показывает ноды локально (не трогает БД).

### Панель архива

Боковая панель (≥editor), две секции:
- **Неактуальные**: список (заголовок, важность, теги) → «Вернуть», «Удалить».
- **Удалённые**: «Восстановить» (обратно на канвас в прежнюю позицию), «Стереть навсегда» (purge; подтверждение, предупреждение про «ссылка удалена» у связанных заметок).

### Drag & drop файлов

- Drop на канвас: `.md/.txt` → новая заметка в точке дропа (тело = содержимое); картинка/аудио — тост «Файлы можно добавить внутри заметки».
- Drop в редактор заметки: картинка → вставка в текст; аудио → аттачмент с плеером; `.md/.txt` → вставка содержимого в курсору (без создания заметки).
- Валидация размера/типа на клиенте + сервере; прогресс-бар загрузки, ошибка — тост.

### Пустые/загрузочные состояния

Скелетон графа при загрузке; empty-state пустого канваса с подсказкой; ошибки сети — retry-баннер.

## 3. Редактор заметки (модалка/панель справа)

- Поля манифеста: заголовок (инпут), важность (сегмент 1–5), теги (мульти-чипы с автодополнением), актуальность (toggle), доступ (кнопка → диалог «Доступ»), статус-бейдж автора.
- Tiptap-редактор markdown: toolbar (H1–H3, bold/italic, список, код, ссылка, картинка-upload), **автодополнение `[[`** по заметкам канваса (по заголовку, с превью позиции), вставляет `[[uuid|Заголовок]]`, рендер — чип-ссылка с иконкой.
- Секция «Файлы»: список аудио/прочих аттачментов с плеером (native `<audio controls>`) и удалением.
- Кнопки: Сохранить (PATCH манифеста + PUT тела), Закрыть; автосохранение тела раз в 30 с — не в v1, только по кнопке.
- Не-редактор (viewer) видит read-only рендер markdown.

## 4. Диалог «Доступ» (канвас и заметка — одинаковый)

- Сегмент: «Только я» / «Конкретные пользователи» / «Публичная ссылка».
- При «Публичная ссылка»: URL `…/shared/canvas/{slug}`, кнопка «Копировать», «Выключить ссылку».
- При «Конкретные пользователи»: поле email + роль viewer/editor + «Пригласить»; список выданных доступов (роль, удалить/изменить).
- Инвайт по email: письмо со ссылкой на принятие (если юзера нет — pending-инвайт, резолвится при регистрации).

## 5. Shared-виды (анонимы, viewer)

Только просмотр: зум/панорама/клики по нодам (открытие read-only заметки), подсветка тегов, фильтр важности. Никаких контекстных меню, drag запрещён. Баннер «Публичная версия — только чтение».

## 6. Toast-уведомления

Успех (сохранено/приглашено), ошибка сети, 401→авто-рефреш прозрачно; повторный 401 → редирект на /login с тостом «Сессия истекла».

## 7. Горячие клавиши (v1)

| Клавиша | Действие |
|---|---|
| ПКМ | контекстное меню |
| Del (при выбранной ноде) | удалить (editor) |
| Ctrl+F | фокус на поиск по канвасу |
| Esc | закрыть меню/модалку, отменить связывание |
| Ctrl+колесо | зум к курсору |

## i18n

Все строки через `t('…')`, словари `locales/ru.json`, `locales/en.json`. Переключатель в шапке и в профиле, выбор в localStorage + `navigator.language` по умолчанию.
