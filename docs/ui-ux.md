# UI/UX спецификация

Язык интерфейса: RU по умолчанию, переключатель EN (vue-i18n). Тёмная/светлая тема — не в v1, только светлая. Все стили — свой CSS, дизайн-токены в `src/styles/tokens.css`, базовые классы компонентов — `src/styles/components.css`. Headless-примитивы (поведение и доступность без стилей) — Reka UI, компоненты-обёртки живут в `src/components/ui/`.

## Карта экранов и маршруты

| Маршрут | Экран | Доступ |
|---|---|---|
| `/` | Лендинг (маркетинг) | все |
| `/login`, `/register`, `/verify-email`, `/forgot-password`, `/reset-password` | auth | гости |
| `/dashboard` | Dashboard (список канвасов) | auth |
| `/canvas/:id` | CanvasView (редактор) | ≥viewer (edit по правам) |
| `/shared/canvas/:slug` | SharedCanvas | все (в т.ч. анонимы) |
| `/shared/canvas/:slug/note/:noteId` | SharedNote (read-only заметка) | все |
| `/profile` | Настройки профиля | auth |
| `*` | 404 | |

> Примечание (R04): изначально Dashboard был на `/`; лендинг занимает `/`, поэтому Dashboard вынесен на `/dashboard`.

Route guards: `requires-auth` (нет сессии → `/login`) и `guest-only` (авторизованного с `/login`, `/register` → `/dashboard`). Отдельного guard «verified» нет: войти без подтверждённого email нельзя.

## 0. Лендинг (`/`)

Hero с описанием продукта и иллюстрацией графа, блок из 3–4 ключевых возможностей (канвас, ссылки, теги, шеринг), кнопки «Войти» и «Регистрация» (авторизованному вместо них — «Открыть дашборд»), переключатель RU/EN, футер.

## 1. Dashboard

- Сетка карточек канвасов: название, дата изменения, кол-во доступных заметок, бейдж роли (владелец/editor/viewer), бейдж «публичный» если канвас `public`. Канвасы, к которым выдан доступ, показываются в том же списке с бейджем роли.
- Кнопка «+ Создать канвас» → модалка с названием → редирект на `/canvas/:id` (пустой канвас с подсказкой-заглушкой «ПКМ — создать заметку»).
- Входящих приглашений и «колокольчика» нет: доступ, выданный существующему пользователю, действует сразу и появляется в списке; ожидающий инвайт превращается в доступ после регистрации и подтверждения email.
- Поиск/сортировка канвасов — не в v1 (список постраничный).

## 2. CanvasView

Верхняя панель: название канваса (инлайн-edit **только для владельца**), поиск по заметкам (лупа, выпадающий список результатов: заголовок + совпавший тег → клик центрирует ноду), кнопки: Теги · Важность · Архив · Доступ · Профиль. «Доступ» и «Архив» — только для тех, у кого есть соответствующие права (Доступ — владелец, Архив — editor канваса и выше).

### Ноды

- Прямоугольник ~220px, виден **только заголовок** (1–2 строки, ellipsis). Приватная заметка помечена иконкой замка.
- Обводка/акцент цвета зависит от важности: 1 — серый slate, 2 — синий, 3 — нейтральный (по умолчанию), 4 — оранжевый, 5 — красный. Легенда в меню важности.
- Состояния: обычная, hover (подсветка), selected (акцент-рамка + handles), drag (тень), «неактуальная» — не рендерится без фильтра; при включённом фильтре — полупрозрачная с бейджем «архив».
- Открытие заметки: двойной клик или ПКМ → «Открыть».
- Drag, resize (handles справа/снизу, ширина 120–800), зум бесконечный (minimap не в v1), панорамирование колесом/SPACE+drag, Ctrl+колесо — зум к курсору.

### Рёбра (линки)

- **Прямые**: сплошная линия, стрелка на конце (направленные родитель → дочерняя).
- **Косвенные** (из `[[...]]` в тексте): пунктирная линия со стрелкой, тоньше, цвет приглушённый.
- **«Ссылка удалена»** (`state: removed`): серый пунктир с подписью «ссылка удалена». Для стёртой навсегда цели (только косвенные) — висячая линия без конца, видна авторизованным пользователям с доступом к заметке-источнику; для цели в корзине — линия к «призраку» ноды с кнопкой «восстановить», только editor и выше. Остальные не видят ничего.
- Выделение ноды подсвечивает все её рёбра; при hover ноды — её связи жирнее.
- **ПКМ по прямой связи** (editor+): «Развернуть направление», «Удалить связь»; клавиша Del при выбранной связи — удалить. У косвенных связей меню нет (меняются правкой текста).

### Контекстное меню (ПКМ)

**По пустой области канваса:**
1. Создать заметку (в точке клика)
2. Импортировать файл… (`.md/.txt` → новая заметка; аналог drop)
3. Зум-в центр

**По ноде заметки:**
1. Открыть
2. Создать от этой заметки → спавнит дочернюю ноду рядом + сплошная стрелка родитель → новая
3. Ссылка на другую заметку… → режим связывания (клик по целевой ноде), создание прямой ссылки
4. Теги (подменю: чекбоксы тегов канваса + «новый тег…»)
5. Важность (подменю 1–5)
6. Сделать публичной / приватной (переключает видимость заметки; только автор и владелец канваса)
7. Доступ… (диалог «Доступ» заметки; только автор и владелец канваса)
8. Поместить в архив «неактуально»
9. Удалить (soft → в архив удалённых)

Полное меню — для editor канваса и выше (пункты 6–7 — только автор/владелец). Viewer и editor только этой заметки видят «Открыть».

### Меню тегов

Панель со списком тегов канваса (чип с цветом). **Hover по тегу** подсвечивает все ноды с этим тегом (остальные — dimmed). Клик по тегу для editor канваса и выше — переименовать/сменить цвет/удалить (подтверждение: «Тег будет удалён из N заметок»).

### Меню важности

Чекбоксы 1–5 + «Показывать неактуальные» + легенда цветов. Фильтр скрывает/показывает ноды локально (не трогает БД).

### Панель архива

Боковая панель (editor канваса и выше), две секции (каждая — постраничная):
- **Неактуальные**: список (заголовок, важность, теги) → «Вернуть», «Удалить».
- **Удалённые**: «Восстановить» (обратно на канвас в прежнюю позицию), «Стереть навсегда» (purge; подтверждение, предупреждение про «ссылка удалена» у связанных заметок). Стёртые навсегда в списке не показываются.

### Drag & drop файлов

- Drop на канвас: `.md/.txt` → новая заметка в точке дропа (тело = содержимое); картинка/аудио — тост «Файлы можно добавить внутри заметки».
- Drop в редактор заметки: картинка → вставка в текст; аудио → аттачмент с плеером; `.md/.txt` → вставка содержимого в курсор (без создания заметки и без загрузки на сервер).
- Валидация размера/типа на клиенте + сервере; прогресс-бар загрузки, ошибка — тост.

### Пустые/загрузочные состояния

Скелетон графа при загрузке; empty-state пустого канваса с подсказкой; ошибки сети — retry-баннер.

## 3. Редактор заметки (модалка/панель справа)

- Поля манифеста: заголовок (инпут), важность (сегмент 1–5), теги (мульти-чипы с автодополнением; создание новых — для editor канваса и выше), актуальность (toggle), видимость «публичная/приватная» и кнопка «Доступ» (только автор и владелец канваса), статус-бейдж автора.
- Tiptap-редактор markdown: toolbar (H1–H3, bold/italic, список, код, ссылка, картинка-upload), **автодополнение `[[`** по заметкам канваса (по заголовку, с превью позиции), вставляет `[[uuid|Заголовок]]`, рендер — чип-ссылка с иконкой.
- Секция «Файлы»: список аудио/картинок с плеером (native `<audio controls>`) и удалением.
- Кнопки: Сохранить (PATCH манифеста + PUT тела), Закрыть; автосохранение тела раз в 30 с — не в v1, только по кнопке.
- Viewer видит read-only рендер markdown.

## 4. Диалог «Доступ»

**Канвас** (только владелец):
- Сегмент: «Только я» / «Публичная ссылка».
- При «Публичная ссылка»: URL `…/shared/canvas/{slug}`, кнопка «Копировать»; возврат на «Только я» выключает ссылку (старый URL перестаёт работать).
- Блок «Пользователи»: поле email + роль viewer/editor + «Выдать доступ»; список выданных доступов (роль, изменить/отозвать) и ожидающих (бейдж «ждёт регистрации», отозвать).

**Заметка** (автор и владелец канваса):
- Переключатель «Публичная (по правам канваса)» / «Приватная».
- Блок «Пользователи»: то же самое, но на эту заметку (для приватной заметки — единственный способ дать к ней доступ).

Поведение выдачи: аккаунт есть — доступ действует сразу (тост «Доступ выдан»), аккаунта нет — «Приглашение отправлено, доступ появится после регистрации».

## 5. Shared-виды (анонимы и любые посетители)

Только просмотр: зум/панорама/клики по нодам (открытие read-only публичной заметки на `/shared/canvas/:slug/note/:noteId`), подсветка тегов, фильтр важности. Никаких контекстных меню, drag запрещён, приватные заметки и `removed`-рёбра не приходят. Баннер «Публичная версия — только чтение».

## 6. Toast-уведомления

Успех (сохранено/доступ выдан), ошибка сети, 401→авто-рефреш прозрачно; повторный 401 → редирект на /login с тостом «Сессия истекла».

## 7. Горячие клавиши (v1)

| Клавиша | Действие |
|---|---|
| ПКМ | контекстное меню |
| Del (при выбранной ноде/прямой связи) | удалить (editor+) |
| Ctrl+F | фокус на поиск по канвасу |
| Esc | закрыть меню/модалку, отменить связывание |
| Ctrl+колесо | зум к курсору |

## i18n

Все строки через `t('…')`, словари `locales/ru.json`, `locales/en.json`. Переключатель в шапке и в профиле, выбор в localStorage + `navigator.language` по умолчанию.
